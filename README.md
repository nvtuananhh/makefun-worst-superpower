`main.py` writes one original funny line — the worst superpower imaginable, a gift with a catch that makes it useless — to `/output/entry.txt` and prints it.

> I can read minds — but only my own, and it just keeps asking where I left my keys.

82 characters, one line. Standard library only, no network, deterministic.

## Run it

```sh
python3 main.py
```
